# Telecom Customer Churn ML Pipeline

This project demonstrates a modular machine learning pipeline for telecom customer churn prediction.

## Project Structure

- data_loading.py
- preprocessing.py
- feature_engineering.py
- model_training.py
- evaluation.py
- pipeline_runner.py

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn

## Dataset

Telecom Customer Churn Dataset
